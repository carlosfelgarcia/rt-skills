# Resources: pipeline

Trusted sources for the lesson writer. Cite these for a claim about Python or a host; cite the code under review for a claim about the pipeline. For a package in `requires`, its released source under `/software/packages/<name>/<version>/` beats any page about it.

## Knowledge

- [Python documentation](https://docs.python.org/3/)
  The language and the standard library. Use for: syntax, `pathlib`, `subprocess`, `logging`, typing.
- [Houdini Object Model (hou)](https://www.sidefx.com/docs/houdini/hom/)
  The `hou` Python API. Use for: nodes, parameters, undo groups and expressions in Houdini.
- [Nuke Python Developer's Guide](https://learn.foundry.com/nuke/developers/latest/pythondevguide/)
  Use for: the `nuke` module, callbacks and panels.
- [Autodesk Maya Help](https://help.autodesk.com/)
  The `maya.cmds` and OpenMaya references. Use for: Maya scripting and scene data.
- [OpenUSD documentation](https://openusd.org/release/)
  Use for: stages, layers, composition and the `pxr` API.
- [rez documentation](https://rez.readthedocs.io/)
  Use for: `package.py`, `requires` ranges and how environments resolve.
- [ShotGrid Python API](https://developers.shotgridsoftware.com/python-api/)
  Use for: `find`, `update`, entities, fields and filters.
- The reviewed repo's `GLOSSARY.md` and `docs/adr/`
  Use for: the repo's own terms, and why its design is the way it is.
