# Resources: swift-app

Trusted sources for the lesson writer. Cite these for a claim about Swift or an Apple framework; cite the code under review for a claim about the app.

## Knowledge

- [Apple Developer Documentation](https://developer.apple.com/documentation/)
  The API reference for every Apple framework. Use for: SwiftUI, SwiftData, Foundation, CloudKit and the other framework types.
- [The Swift Programming Language](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/)
  The language book. Use for: syntax, error handling, generics, protocols and the concurrency chapter.
- [Swift Evolution proposals](https://github.com/swiftlang/swift-evolution/tree/main/proposals)
  The design record of each language feature, with its motivation. Use for: why a feature works the way it does, such as `Sendable`, actor isolation or default isolation.
- [WWDC session videos](https://developer.apple.com/videos/)
  Apple engineers explain a framework with worked examples. Use for: Read next, when a session covers the lesson's topic.
- [Swift Testing documentation](https://developer.apple.com/documentation/testing)
  Use for: `@Test`, `#expect`, traits and parameterized tests.
- The reviewed repo's `GLOSSARY.md` and `docs/adr/`
  Use for: the repo's own terms, and why its design is the way it is.

## Wisdom

- [Swift Forums](https://forums.swift.org)
  The language and its evolution, discussed by its designers. Use for: questions the documentation does not settle.
