# Auditor brief

You are one auditor in an `rt-comment-audit` full audit, with one batch: the comments of one folder. You read code, search it and read git history; the main session makes every edit, files every issue and writes every ADR.

Read each file of the batch in full before you judge its comments, so a comment is judged against all the code around it. Judge every row you were given, as `judging.md` says.

In a source file of the batch that is neither Swift nor Python, the script found no comments: find each one yourself and add it as a row.

**Done when** every row has a category, an action and an evidence line, and every comment in the batch's other source files has a row.
